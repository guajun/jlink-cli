jlink-cli

A Go-first command-line interface that gives AI agents predictable, non-interactive access to SEGGER J-Link discovery, diagnostics, and scripted connection workflows.

Install from GitHub Releases

1. Install the CLI binary

The CLI binary and Agent Skills are installed separately. These one-line installers install only the binary and do not include skills. Install optional skills with gh skill install below; skills do not install the binary.

Windows PowerShell

Downloads the latest Windows release asset and installs jlink-cli.exe into %LOCALAPPDATA%\Programs\jlink-cli\bin.

irm https://github.com/guajun/jlink-cli/releases/latest/download/install.ps1 | iex

Linux shell

Downloads the latest Linux release asset and installs jlink-cli into ~/.local/bin.

curl -fsSL https://github.com/guajun/jlink-cli/releases/latest/download/install.sh | sh

Optional agent setup

2. Install Agent Skills with gh

Use a GitHub CLI version with gh skill install support. This installs skill files only. Install the CLI binary separately using step 1.

Agent Skills

Install skills with GitHub CLI.

gh skill install guajun/jlink-cli

Agent-first defaults

Commands are designed for stable JSON output, stderr diagnostics, and non-interactive execution so automation can inspect local J-Link readiness safely.

Release assets

GoReleaser publishes single-file binaries for Windows, Linux, and macOS on every tagged release.

Physical sessions stay explicit

Connection workflows default to dry-run behavior unless callers opt in with --yes.
